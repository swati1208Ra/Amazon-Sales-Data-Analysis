# 🛒 Amazon Sales Data Analysis

## 📌 Project Overview
This project focuses on analyzing an Amazon sales dataset to extract meaningful business insights. The goal was to clean the raw data, analyze product categories, and build an interactive dashboard to visualize key performance indicators (KPIs).

## 🎯 Objectives

- Analyze the distribution of products across categories
- Identify categories with the highest number of products
- Compare average ratings across categories
- Create a professional dashboard with key KPIs and charts
- Present the analysis in a simple and portfolio-ready format

## 🛠️ Tools Used
- **Spreadsheet Software:** LibreOffice Calc 
- **Techniques:** Data Cleaning, Pivot Tables, Cell Linking, Data Visualization (Bar Charts)

## 📈 Dashboard Features
- **Cleaned Data:** Removed overlapping and messy text for clear presentation.
- **Top 10 Filtering:** Filtered categories to show only the Top 10 for better readability.
- **Visuals:** Horizontal Bar Charts with explicit data labels for easy metric tracking.
